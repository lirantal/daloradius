# UNIT-029 — validation OTP des opérateurs

`app/operators/login-otp.php` consomme désormais les compteurs TOTP et les codes de récupération avec PDO. La table des opérateurs configurée est contrôlée comme identifiant SQL et doit utiliser InnoDB. La lecture de la ligne et la mise à jour de `lastlogin` avec l'état à usage unique sont effectuées sur le même handle et dans une seule transaction.

Le verrou `FOR UPDATE` protège contre deux consommations simultanées. L'ID, le nom, la source d'authentification et l'identité LDAP en attente sont revérifiés sous verrou ; la ligne doit toujours avoir le MFA actif. Un code déjà consommé, une identité modifiée, une mise à jour échouée ou un commit échoué ne crée pas de session authentifiée. La régénération de la session vient **après** le commit. Pour une ancienne session locale en attente créée avant la migration LDAP, une projection sans `auth_source` ni `external_id` est utilisée uniquement lorsque la base signale une colonne absente. Les contrôles CSRF et la limite de cinq essais sont conservés.

Validation isolée : `OPERATOR_OTP_BASELINE=1 python3 tests/operator_otp_http.py` contre la page PEAR du commit `3da3c90ebeff36741ec238246778dd406ade4fc4`, puis `python3 tests/operator_otp_http.py` contre PDO. Les parcours HTTP/PHP/MariaDB couvrent TOTP, rejeu, récupération, invalidation après cinq erreurs, identité LDAP en attente, deux vérifications concurrentes et l'ancien schéma local. Les cas PDO supplémentaires couvrent des entrées malformées, des erreurs injectées sur chaque type de mise à jour avec vérification de l'état inchangé, et le refus d'une table MyISAM. Le test PHP de flux d'authentification et les régressions ciblées sont exécutés séparément.

Ces essais utilisent des bases, conteneurs, sessions et facteurs factices jetables. Aucune clé, aucun mot de passe, jeton, secret ou identifiant de connexion ne doit être conservé. Ils ne constituent ni un déploiement ni une authentification contre un véritable annuaire LDAP. L'authentification primaire PDO demeure distincte et les lectures partagées d'ACL hors de cette unité.
