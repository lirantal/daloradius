# R01c — Operator catalog and residual AJAX bootstrap

Base: `523113375b234f56035b8e9dd92d2c6c3ffcf776`, branch `refactor/pdo`.

## Scope and reconciliation

- RES-049: `app/operators/config-operators-list.php` now counts and fetches its
  displayed six-column catalog on an explicit private PDO connection. Sort columns
  and direction are allowlisted; LIMIT/OFFSET are bound integers; the configured
  table identifier is validated/quoted and the selected session backend retained.
- RES-112: `app/operators/library/ajax/user_actions.php` no longer opens PEAR.
  Current-source inspection showed an unused `db_open.php` include, **not** a
  remaining operator-ID query. Business actions were already PDO; R01a converted
  the independent ACL gate. The stale comment/plan wording is corrected, without
  inventing another lookup or changing those business mutations/SMTP policies.
- Necessary R02 dependency: `get_operators()` only, in
  `app/operators/include/management/populate_selectbox.php`. The real list-page
  sidebar calls it, formerly through PEAR `list_from_db()`. The initial native
  legacy-open tripwire caught that indirect dependency after the page's own PDO
  reads succeeded. This selector now owns a private read-only PDO connection,
  keeps DISTINCT/ascending raw username-list semantics and never closes a caller's
  connection/transaction. Other selectors and `list_from_db()` remain legacy.

Preserved: login/ACL gates, selected database location, custom operator table,
COUNT(id), the six sort keys and default id descending, configured page size,
pagination, Local/LDAP labels, linked/not-linked labels, CONCAT name semantics,
HTML escaping and deletion form/control behavior. List data is fetched before
emitting its table; errors show a generic failure, not a partly populated table or
raw driver details. Only exception classes are logged. There are no writes, schema
changes, new write locks or consistency-snapshot guarantees for these independent
reads. Count-versus-page races remain possible as in the original two-query list.

Intentional improvements: NULL display values are cast safely; array-valued sort
controls fall back to the normal allowlisted defaults rather than causing the
baseline's reproducible `strtolower()` TypeError. Invalid identifiers, invalid page
size and a missing catalog fail with a generic message. A selector error returns
an empty menu list without leaking database details. SQL templates contain LIMIT
placeholders instead of interpolated pagination values.
