# UNIT-032 — Changement des attributs de mot de passe RADIUS

`app/users/pref-auth-password-edit.php` emploie PDO pour le contrôle des attributs `radcheck` et leur modification. Le nom de table provient exclusivement de `CONFIG_DB_TBL_RADCHECK` après validation de l'identifiant ; les valeurs SQL sont liées. Une table non transactionnelle est refusée. Dans une seule transaction InnoDB, les lignes `op=':='` et `attribute LIKE '%-Password'` de l'utilisateur connecté sont lues sous verrou par ordre d'ID ; les attributs dont la valeur vérifie l'ancien mot de passe sont modifiés ensemble, ou tous annulés. Les autres valeurs, opérateurs et comptes restent inchangés. Les algorithmes et les messages de succès/échec habituels restent ceux de la page, notamment le nombre de lignes correspondantes. L'UPDATE vérifie l'ID, l'utilisateur, l'attribut, l'opérateur et les octets de l'ancienne valeur. Aucun SQL interpolant un mot de passe n'est transmis aux journaux de débogage ni affiché ; les exceptions sont réduites à leur classe dans le journal d'erreur.

Validation : `RADIUS_CHANGE_TEST=1 RADIUS_CHANGE_BASELINE=1 PYTHONDONTWRITEBYTECODE=1 python3 tests/portal_login_http.py` puis `RADIUS_CHANGE_TEST=1 PYTHONDONTWRITEBYTECODE=1 python3 tests/portal_login_http.py` dans des installations HTTP/PHP/MariaDB jetables, avec la page PEAR épinglée à `894e04924` pour la référence. Sont comparés : six attributs de quatre familles de hash et deux formes de texte/crypt, mauvais mot de passe, confirmation invalide, compte sans attribut, nom Unicode avec apostrophe et CSRF. Le candidat couvre en plus les contrôles malformés, une erreur sur un attribut tardif avec restauration des écritures antérieures, le refus d'une table MyISAM, la valeur NULL dans un schéma ancien nullable, deux sessions concurrentes avec deux workers PHP, et l'absence des mots de passe dans la réponse lorsque le débogage SQL sur la page est actif. Il ne s'agit ni d'un déploiement ni d'une validation de production. **Aucune clé, aucun mot de passe, jeton, secret ou identifiant de connexion ne doit être conservé.**
